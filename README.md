## Deskripsi
Web Page To-Do List yang dinamakan **Toolis (ToDo List)**, kini diperbarui dengan interaktivitas penuh menggunakan JavaScript (DOM Manipulation). Web ini mengintegrasikan manajemen data tugas berbasis objek secara dinamis tanpa memerlukan *refresh* halaman, dilengkapi fitur toggle Dark/Light Mode, serta opsi edit dan hapus tugas.

## Fitur Baru (E02a)
- **Manipulasi DOM Interaktif:** Penambahan tugas baru langsung ditampilkan secara dinamis ke dalam daftar.
- **Manajemen Tugas:** Tombol untuk **Edit**, **Delete**, dan **Checkbox** untuk menandai tugas yang selesai.
- **Penyimpanan State Berbasis Objek:** Data disimpan dalam bentuk *array of objects* di dalam memori JavaScript.
- **Toggle Dark/Light Mode:** Mengubah tema tampilan secara dinamis dengan manipulasi kelas CSS pada elemen `body`.
